# Entrega · FlashDelivery

## Aplicación

Proyecto monolítico CRUD de FlashDelivery, con el código fuente organizado en `src/`. Para ejecutarlo localmente, instala Node.js 18 o posterior y ejecuta `npm start`; luego abre `http://localhost:3000`.

## Repositorio personal

Enlace del proyecto publicado: [github.com/omargit2001/DELYVERY](https://github.com/omargit2001/DELYVERY).

Para publicarlo, crea un repositorio vacío en tu cuenta de GitHub y ejecuta desde la carpeta del proyecto:

```bash
git init
git add .
git commit -m "Construye aplicación CRUD de FlashDelivery"
git branch -M main
git remote add origin https://github.com/TU-USUARIO/flashdelivery-operations.git
git push -u origin main
```

Después, sustituye la nota pendiente de arriba por la URL real del repositorio. No se puede publicar en una cuenta personal sin que el propietario proporcione el repositorio y complete la autorización de GitHub.
